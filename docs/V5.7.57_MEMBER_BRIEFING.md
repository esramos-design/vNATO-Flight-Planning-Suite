# Virtual NATO Flight Planning Suite — V5.7.57 Member Briefing

Release date: 14 September 2026  
Channel: TEAM LIVE

## What changed

- SimBrief plans can be applied to ICAO, SWIFT, or both workspaces for review and military/mixed-rule editing.
- Corrected SimBrief speed and cruising-level transfer to SWIFT.
- Bare SimBrief values are normalized for flight-plan use (for example, 0482 becomes N0482 and 300 becomes F300).
- SWIFT endurance is formatted in its dedicated field as HH:MM and is excluded from SWIFT remarks.
- Full ICAO output continues to retain Item 19 endurance as E/HHMM.
- Added local ICAO and SWIFT flight-test reports for easier issue reporting. Reports are generated only on request and are not uploaded.

## Member action

Refresh the TEAM LIVE page with Ctrl+F5 before the first use. Import a current SimBrief OFP, select Apply to SWIFT or Apply to Both, and verify the resulting route, speed, level, rules and remarks before filing.

## Operational disclaimer

This software is exclusively for simulated virtual aviation environments. It must not be used for real-world flight planning, navigation or operational dispatch.
