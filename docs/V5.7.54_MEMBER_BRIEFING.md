# Virtual NATO Flight Planning Suite — V5.7.54 TEAM LIVE

Release date: 13 September 2026  
Channel: TEAM LIVE  
Release: SimBrief ICAO and SWIFT Dual-Target Import

## What is new

- Import the latest SimBrief OFP using a Pilot ID or username without entering a SimBrief or Navigraph password.
- Review the complete OFP preview before changing Suite fields.
- Choose **Apply to ICAO**, **Apply to SWIFT**, or **Apply to Both**.
- Continue editing imported routes for military OAT, VFR, IFR and mixed Y/Z operations before generating the final output.
- Use one combined **SWIFT Route & Remarks** workspace while retaining separate generated Route and Remarks copy outputs.
- Use the refreshed right-side operational guides and the Oceanic first-step checklist.
- Follow the MSFS Mach Bridge checklist before Oceanic use; when the bridge is offline, leave Mach blank rather than deriving it from VATSIM groundspeed.

## SimBrief import safeguards

- Existing Suite fields are not changed until an Apply action is selected.
- Aircraft capabilities and SimBrief remarks remain optional.
- The latest fetched plan remains in browser memory only until reload or another fetch.
- Imported content must be reviewed and may be edited before use.

## Member verification

1. Hard-refresh TEAM LIVE with **Ctrl+Shift+R**.
2. Confirm the footer displays **V5.7.54** and **TEAM LIVE**.

4. Test ICAO and SWIFT separately before using **Apply to Both**.

## Operational limitation

The approved Operational Disclaimer remains in force. The Suite is exclusively for simulated virtual aviation and must never be used for real-world flight planning, navigation or operational dispatch.
