# vNATO Flight Planning Suite — V5.7.49 TEAM LIVE

V5.7.49 is now available to all Virtual NATO members.

This release improves mixed IFR/VFR flight-plan filing through myVATSIM. For ICAO `Y` or `Z` plans, members can keep the canonical ICAO copy or use the optional **Copy VATSIM version**. The VATSIM version selects the initial IFR/VFR rule supported by myVATSIM and carries the original mixed-rule transitions in RMK.

The Suite now also provides direct buttons for both the current and BETA myVATSIM forms, uses matching copy-box layouts, and retains saved ICAO profile details including PBN and PER.

Please review all imported fields before filing, especially Flight Rules, route transitions, RMK, endurance and date. Coordinate operational rule changes with ATC as required.
