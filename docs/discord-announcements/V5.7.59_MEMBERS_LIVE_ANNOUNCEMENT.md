# V5.7.59 is now LIVE

The Virtual NATO Flight Planning Suite has been updated to **V5.7.59 TEAM LIVE**.

This release keeps the theme image and main navigation controls visible while the left and right working areas scroll independently on desktop and tablet. Mobile operation retains normal page scrolling.

The DAY theme also now includes corrected C-17 artwork with accurate four-engine geometry and a corrected airframe silhouette.

Please refresh the LIVE page once before use. If you still see the previous layout or DAY image, use `Ctrl+F5`.

Flight-planning, SimBrief, SWIFT, VATSIM and Oceanic functions are unchanged by this release.
