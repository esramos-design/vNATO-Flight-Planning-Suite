# Virtual NATO Flight Planning Suite — V5.7.63 Member Briefing

Release date: 23 September 2026  
Channel: TEAM LIVE

## What changed

- Oceanic now uses the native Windows **vNATO MSFS Mach Bridge** for local MSFS telemetry.
- The bridge is installed per-user under `%LOCALAPPDATA%\vNATO\MachBridge`.
- The installer is distributed as a GitHub Release asset rather than through Cloudflare Pages.
- The bridge registers `vnato-mach://`, binds only to `127.0.0.1:8765`, and exposes read-only telemetry.
- Python, PowerShell, and the previous CMD installer are no longer required for the normal setup path.

## Member action

On first use of Oceanic live Mach telemetry, select **Install Bridge Once**, complete the Windows installer, load MSFS into an aircraft, then select **Start Bridge**.

## Preserved behaviour

VATSIM/SWIFT, SimBrief, OAT/GAT, Y/Z, STAY/STAYINFO, existing flight-planning workflows, theme behaviour, and the locked Operational Disclaimer remain unchanged by this release.
